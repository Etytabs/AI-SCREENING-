# AI/ML Roadmap

## 1. Foundation
Ingestion, normalization, eligibility rules, lexical similarity, provenance, audit, evaluation fixtures.

## 2. Semantic intelligence
Sentence-transformer embeddings, candidate retrieval, publication entity resolution, duplicate detection, proposal similarity.

## 3. Decision intelligence
Calibrated confidence, evidence chains, anomaly detection, reviewer workflows.

## 4. Learning loop
Reviewer feedback, labeled evaluation sets, model monitoring, MLflow experiments, controlled model updates.

Use the simplest validated model for each task. Add LLM reasoning only where it provides measurable value.
