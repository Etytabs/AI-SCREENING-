# Pilot Scope

### Grant screening
Use RIGMS/historical applications and the applicable eligibility checklist when those datasets are available.

### Publication reconciliation
Start with the national/local repository plus available DOI/publication datasets. International databases are optional connectors.

### Human oversight
AI outputs are decision-support recommendations. Humans remain responsible for consequential approvals, rejections, and record changes.

### Data integrity
Do not fabricate missing records or metrics. Retain source, version/date, transformation, validation status, and uncertainty where applicable.
